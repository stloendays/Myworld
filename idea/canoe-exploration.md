# 创意 03｜独木舟探索（Canoe Exploration）

**状态：待评估／尚未实施。** 现有湖岸已有独木舟和桨的美术道具；此想法是把它升级为可上船、可驾驶的平静湖面探索工具。

## 玩家体验

1. 到岸边或码头指定安全位置，按 `E` 上船。
2. 以第三人称近距离镜头或第一人称坐船镜头缓慢前进、倒退、转向；有划桨动画、轻微船身摇摆、水花和近距离水声。
3. 沿岸寻找一个隐秘的小湾、漂流瓶或第二封信；看见不同视角的日落与湖面倒影。
4. 在有岸滩／靠泊点时按 `E` 离船并恢复步行。

**不做：** 深水游泳、翻船死亡、复杂真实流体模拟、远洋地图、在船上建造。

## 现有工程的实际限制（必须先处理）

- `scripts/world/LakeBuilder.gd` 的湖泊采用定制 shader 和 **玩家涉水约 0.7m 的限制**；码头入水部分有栏杆，这是为了防止第一人称角色掉入深水。
- 驾船必须为船只设置独立运动和碰撞规则，**不能直接删除玩家 `water_limit` 保护墙**；上下船时也要通过有效的状态转换避免把玩家放入受限水体。
- 地图仅 250×250 m，优先沿现有湖岸设计 2–3 个真正值得停靠的点，不为“航行感”盲目扩大地图。
- 不能为了开船切换到另一份湖泊场景。地理坐标来源应为 `data/world/world_layout.json`。

## Godot 实施建议

- 先做**运动学船只**：独立船控制器（例如 `CharacterBody3D` 或显式控制的 `Node3D`＋碰撞），沿湖水平面限速、缓加速、平滑转弯、靠岸阻尼；只有必要时才升级到 `RigidBody3D` 动态浮力。
- 上船与下船都使用现有 `InteractionSystem` 风格的交互契约。保存 `is_boating`、`boat_uid`、安全靠泊点 ID、船只位姿（注意存档版本迁移）。
- 可以用单独的船载 `Camera3D` / `Phantom Camera` 管理镜头，不影响 `FirstPersonController` 的常规输入；船移动时把人保持在安全乘坐点。
- 需要两个坐标明确的靠泊区；海岸线、码头碰撞、水面光照保持与 M1 一致。

## MVP 验收

- [ ] 上船／下船可反复完成，角色不会卡进船体、栏杆、岸边或落入深水。
- [ ] 驾船能起步、转向、减速、靠岸，不穿越地形或出地图边界。
- [ ] 船只与人物不在摄像机切换时瞬移；Esc／F3 仍正常使用。
- [ ] 明确“无法靠岸”和“异常退出”时的安全恢复点；重载存档也不会卡死。
- [ ] 在 Forward+ 下湖面／反射效果与船只模型协调，完成性能和连续场景回归测试。

## 拓展方向

漂流瓶、隐秘木栈桥、水鸟、雨中划舟、湖面摄影；与 [gentle-mystery.md](gentle-mystery.md) 的第三封信联动。
