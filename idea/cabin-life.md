# 创意 01｜木屋生活系统（Cabin Life）

**状态：待评估／尚未实施。** 初衷不是做生存模拟，而是让玩家从森林回到小屋后，有舒适且有记忆的活动。

## 核心玩法

1. **点亮生活**：靠近壁炉按 `E` 点燃／熄灭；炉火有暖光、火焰和环境音。台灯、落地灯可独立开关。
2. **坐下来**：对沙发／扶手椅按 `E`，角色进入坐姿或静态欣赏视角；可以随时起身，视角过渡平滑。
3. **听收音机**：切换自然音／纯音乐频道并调节音量；素材使用授权音频；未来可与天气音效混合。
4. **布置自己的角落**：第一轮只做 **2–3 个固定摆放槽**（书架、茶几、照片框），不做自由拖放建造。
5. **留下回忆**：将通过 Lente 或自制相机保存的本地照片陈列在木屋相框（若摄影尚未上线，可先用许可明确的占位图片）。

## 氛围和反馈

- 雨天窗外真实下雨，屋内不出现降雨粒子，屋外雨声随进入木屋逐渐衰减；壁炉火焰与近场声保留。
- 暮色、夜晚、冬天有不同氛围，但生活互动 **不依赖 M2 完成后才可单独测试**。
- 任何活动都允许立刻取消，没有饥饿、体力、每日打卡、失去物品惩罚。

## 与现有 Godot 工程的衔接

- 使用已有 `scenes/buildings/Cabin.tscn`、`scripts/buildings/Cabin.gd`、统一 `scripts/interactions/Interactable.gd` 和 `InteractionSystem.interact(actor, target)`。
- 为新交互物分配稳定的 `uid`，通过 `WorldState.set_interactable_state(uid, state)` 更新；M4 `SaveManager` 序列化并恢复。音效委托给 M3 `AudioDirector`。
- 保留室内 `cabin_interior` 的 zone 判断；不切场景、不传送到独立房间。座位镜头必须可以返回第一人称控制。
- 原有木屋模型和家具尺寸以 Blender 建模源、`Cabin.gd` 碰撞为准；不要移动其世界坐标或破坏门的自动验收。

## MVP 切片（建议）

**第一轮：炉火、两盏灯、一个沙发座位和一个收音机频道。**

- [ ] 交互提示和 `E` 按键响应正确，墙后物体不可隔墙交互。
- [ ] 火焰、灯光、音量状态可开关，反复进入木屋状态稳定。
- [ ] 坐下／起身不会卡碰撞或失去输入，Esc 暂停功能保持有效。
- [ ] 加入存档后，重进游戏恢复炉火／灯／广播选择；版本字段遵守 `schema_version`。
- [ ] 屏幕截图、性能和音频许可分别验证。
