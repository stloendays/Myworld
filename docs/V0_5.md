## 二、闪动：怎么查、改了什么

用 `devtools/FlickerProbe`（10 个机位，固定 30 fps 连续渲染 60 帧逐像素统计）按**玩家的默认设置**测（新加 `dynres` 选项：开着动态分辨率；`legacy` 选项：还原修复前的做法做对比；`quality=` 测各画质档）。

查到的三个根因，都从源头改：

| 根因 | 现象 | 改法 |
|---|---|---|
| 太阳（和月亮）方向每帧连续转动 | 平行光阴影图每帧重画，**站着不动**时阴影边也在像素间来回跳（木屋地板上一道影子 2 秒闪 15 次） | 阴影方向按 0.15° 小步更新（约 1.2 秒一步，影子尖端只挪 2–3 cm），跳时间、换季立刻到位（`EnvironmentDirector.sun_step_deg`） |
| 显卡忙时动态分辨率降到 100 % 以下，FSR 用引擎默认的强锐化 0.2 | 锐化把细草、远处树叶、木板缝的锯齿放大，**走动时**林地、溪边闪得最厉害（以前的探针关了动态分辨率，测不到这种情况） | 随比例连续变化的轻锐化：100 % 不锐化，降到 60 % 时 0.9，中间没有跳变（`PerformanceDirector.fsr_sharpness_for`） |
| 中画质只有单帧 SMAA | 走动时溪边、林道的锯齿闪烁是高画质的两倍 | 中画质也改用 TAA（和高画质一样） |
| 方块人物和小动物的像素噪点贴图没有 mipmap | 走远了身上闪砂点 | 最近邻 + mipmap |

### 探针数据（1280×720，修复前 = `legacy`，都按玩家默认开着动态分辨率）

站着不动（60 帧里闪了 2 次以上的像素占比 / 单个像素最多闪几次）：

| 其余 8 个机位 | 0–0.10 %（飞鸟、松鼠、溪水泡沫） | 不变 |

| 溪上木板桥 | 6.60 % → **4.17 %** | 10.31 % → **5.01 %** |

## 三、解说牌 → 卷轴

`SignBoard` 接口不变（`create(id, style, width, scale)`），外观整套换成卷轴：

- **立架**（室外）：两根木柱、石脚、带小瓦顶的横梁，横梁上一块木签写中文标题（远处 30 m 内能看到，知道是什么），卷轴挂在梁下；
- **斜案**（泳池边、鱼缸前）：木案向后仰 40°，卷轴沿案面往下铺；
- **挂墙**（泳池馆门头招牌）：铜钩挂卷轴；
- 卷轴本体：羊皮纸、上下两根深色木轴、黄铜轴头、红绳穗、下轴中间一个小坠子。
- **平时卷起**；本地玩家（或当前相机）走近 3.6 m（挂墙招牌 9 m）时 0.65 s 平滑展开：下轴往下落，文字按行逐行露出；走远过 0.8 m 回差才卷回，站在边上不会来回卷。
- 文字先按纸宽逐行断好、每行一个 Label3D，只在展开到那一行时才显示：远处没有小字，不闪；不出纸。
- **第三人称**：面朝一幅展开的卷轴时，镜头慢慢拉近到肩后 1.15 m 并往右上偏，头不挡字；转身恢复。
- 正文字号加大（中文 26 → 30、英文 22 → 25）。原有 18 幅内容和翻译一个不丢，新地图上加了 13 幅（湖畔沙之门 1、云海浮岛 6、琥珀沙丘 6），共 **31 幅**。

## 四、新建游戏：玩法与设定

启动大厅首页：**继续上次的世界**（显示世界、第几天、时刻、玩法；v0.4 只存了任务图鉴的，接着那些进度从秋天黄昏开始）、**单人游戏**、**创建房间**（都先进“新建游戏”页）、加入房间。

“新建游戏”页（中英双语）：顶上 9 个一键预设，下面按 5 组排 23 个选项：

| 分组 | 选项 |
|---|---|
| 玩法 | 玩法模式：悠闲漫步 / 探索收集 / 任务冒险 / 摄影 / 挑战（选模式会带上一套开关，之后仍可单独改，页上有一句说明） |
| 世界与出生 | 出生世界（暮色湖畔 / 云海浮岛 / 琥珀沙丘）、出生点（随世界变化：湖畔 7 处、浮岛 5 处、沙丘 5 处）、世界种子（数字 + 随机，决定天气序列、随机开局、动物分布） |
| 时间与天气 | 起始季节、起始时刻（清晨 / 正午 / 黄昏 / 夜晚 / 随机）、起始天气（含随机，季节不允许时自动换）、一天长度（12 / 24 / 48 / 96 分钟 / 时间静止）、每季天数（3 / 6 / 12 / 锁定季节）、天气变化（频繁 / 正常 / 很少 / 锁定不变） |
| 生物与事件 | 小动物数量（没有 / 少 / 正常 / 多，游戏中途也能改）、动物亲人（不躲人）、仙境林地出现（从不 / 晴朗的夜晚 / 每个夜晚）、图腾任务、图鉴记录、收集品 |
| 界面与难度 | 小地图、罗盘条、任务追踪、未发现地点的问号、奔跑体力、游泳体力、夜晚更亮 |

预设：悠闲度假、探险家、冬日仙境、观星之夜、雨季、摄影师、云端旅人（出生在云海浮岛）、沙海寻宝（出生在琥珀沙丘）、硬核挑战。

- **存档**：`SaveManager` 真正启用：`user://saves/world.json`，存档版本 3 → **4**（加入 `rules`、`collections`、`player`）。临时文件 + 原子替换；每 60 秒、换世界、退出时自动存；新建游戏前把旧档备份成 `world.bak.json`。v1–v3 的存档、v0.4 的 `journal.json` 都能迁移读取。
- **联机**：房主的规则放进欢迎包发给访客，房主改了再广播；访客只照着用、不存档，离开房间换回自己的。协议 2 → 3。联机房间都在湖畔（“创建房间”进新建页时出生世界固定为湖畔）。

## 五、其他升级

- **罗盘条**：屏幕上方，方位刻度 + 150 m 内的探索点（问号 / 金点）、收集品、光门，越远越淡；设定里可关。
