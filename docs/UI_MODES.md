# 界面升级与剧情 / 休闲两种模式（M3 扩展，2026-10-27）

分支 `feature/ui-modes`，叠在 PR #32（M3 声音）上，worktree `D:\个人世界\DuskLake-ui`。
这一版做了五件事：重做启动大厅并把自动更新的检查结果放到大厅上；单人游戏分成剧情和休闲两种模式，联机只开休闲；全部界面换成一套统一的样式；英文界面和字幕补齐；卷轴立牌只写一种语言，跟着界面语言走。

## 两种模式

| | 剧情模式 | 休闲模式 |
|---|---|---|
| 内容 | 老图腾的 16 个任务、划船人的信、石头小屋的门锁、三个世界把光送回去的过场、新星座、暮烬之夜与终章 | 没有任务。老图腾只说一句湖边的闲话就道别（6 句里随便挑一句）；石头小屋的门推开就进；八个星座一开始都在天上；不会有暮烬之夜和终章，世界里不放剧情过场 |
| 开局 | 固定的故事开局（秋天黄昏的湖畔，冒险模式，任务、图鉴、收集品都开） | “新的世界…”到设定页：玩法模式（悠闲漫步、探索收集、摄影、挑战，没有任务冒险）、出生世界与出生点、季节时刻天气、一天长度、天气变化、小动物、仙境、图鉴、小地图罗盘、体力、夜晚亮度、种子，10 个一键预设 |
| 存档 | `user://saves/story.json` | `user://saves/casual.json` |
| 联机 | 不能开房间 | 创建房间、加入房间都在休闲模式里 |

- 规则里多了第一个选项“游戏模式” `play`。`GameRules.sanitize()` 保证剧情模式任务、图鉴、收集品一定开，休闲模式没有任务、玩法模式里的任务冒险换成探索收集；各系统用 `GameRules.is_story()` 判断剧情内容（`CottageDoor`、`StarField`、`StoryDirector`、`DialoguePanel`、`MiniWorld.play_story`）。
- 两个存档槽互不覆盖：玩剧情时开一局休闲，剧情那一局原样留着，回大厅点“继续旅程”就接着玩。新开某种模式时只备份这个槽的旧档（`story.bak.json` / `casual.bak.json`）。
- 旧存档：v0.5 的单一存档 `world.json` 第一次启动时按里面的规则复制进槽（开着任务的算剧情、没开的算休闲），原文件留着不动；只有 v0.4 的 `journal.json` 时接进剧情槽。
- 联机只开休闲：正在玩剧情时点“创建房间”，先把剧情进度存好，再换到你的休闲世界（有休闲存档就接着，没有就先到设定页建一个、开局后自动开房间）。访客照房主的本局设定走，本来就是休闲。
- 休闲模式的日志任务页写着“休闲模式没有图腾的任务……想跟着老图腾的故事走，回大厅选剧情模式”。

## 启动大厅

左边一列，右边留给湖景（左深右浅的渐变压暗）：

1. 标题 Dusk Lake 和一行副标题；你的名字。
2. **单人游戏**：剧情、休闲两张模式卡。卡上一句说明、存档进度（世界 · 第几天 时刻 · 任务 n / 16，或玩法模式；没有存档时“还没有开始”；正在玩时前面标“正在玩”），“继续旅程 / 继续”是主按钮（正在玩时变成“回到游戏”），下面是“新的旅程 / 新的世界…”。剧情的“新的旅程”先弹一页确认：有进度时写明第几天、完成几个任务，开始前先备份。
3. **多人游戏 · 休闲模式**：创建房间、加入房间（加入页也写明联机都在休闲模式里玩）。
4. 底下一排：设置（直接打开设置页，关掉回到大厅）、语言、退出游戏。
5. 窗口矮、英文说明长时这一列可以上下滚动，底下那排按钮不会被挤出屏幕。

游戏中 Esc 菜单多了“回到主菜单”（先存档）。菜单顶上写着现在的模式和世界（联机时加“联机中”）。

| 状态 | 显示 | 按钮 |
|---|---|---|

| 在编辑器 / 源码里跑 | 开发版本，不检查更新 | — |

## 界面样式（`UiStyle`）

一套配色只在 `scripts/ui/UiStyle.gd` 里改：暮色深蓝紫的半透明面板、琥珀色的标题和选中、落日橙的主按钮、月光蓝的次要强调、奶白的文字；圆角、细描边、柔和的投影。`GameSettings.ui_theme()` 用 `UiStyle.build_theme()` 建唯一的主题，所有界面都挂它。

| 界面 | 改了什么 |
|---|---|
| 大厅、设定页、加入 / 房间页、剧情确认页 | 重做（见上） |
| 暂停菜单、设置 | 标题、模式与世界一行、按键说明、主按钮；设置页签、滑块、下拉、输入框跟主题；勾选框和开关换成手画的图标（引擎默认的在深色面板上几乎看不见） |
| 交互提示 | 屏幕下方一条药丸条，按键单独画成按键帽（R 钓鱼、E 打开木门……） |
| 短提示 | 上方药丸条，长句自动换行，淡入淡出 |
| 对话框 | 琥珀细边面板，名字琥珀色，选项是整行按钮 |
| 旅行日志、任务追踪栏 | 面板、页签、颜色跟主题；任务追踪栏是半透明药丸 |
| 世界地图 | 右侧总览面板、当前所在的世界高亮 |
| 聊天框、烹饪、棋盘、换装、动作轮盘 | 背景压暗、面板、文字和高亮换成同一套颜色 |

盖住画面的面板（大厅、暂停、日志、世界地图、信、厨房、棋盘）开着时，罗盘条、小地图和任务追踪栏自动收起来，不再压在面板上（`UiStyle.COVER_GROUP` / `CHROME_GROUP`；暂停菜单会暂停世界，所以它开关时主动通知一次）。划船人的信和星图保留信纸的样子。

## 英文

- 新加的界面文字（大厅、模式卡、更新状态、剧情确认页、暂停菜单、日志）全部补了英文，`locale/en.tsv` 共 777 条；自动检查扫一遍所有界面脚本，少一条就失败。
- 字幕：剧情过场的 21 行字幕和标题、开场过场、老图腾的对话和闲话、划船人的信都有英文（数据里的 `*_en`）；界面语言是英文时就显示英文。剧情截图工具加了英文模式：

```
Godot_console.exe --path . --resolution 1600x900 --position 100000,100000 res://devtools/StoryShots.tscn -- story_finale en
```

- 卷轴立牌只写一种语言：界面是中文就只写中文，是英文就只写英文（“跟随系统”时看系统语言）。在大厅或设置里换语言，所有卷轴立刻重写；木签上的标题也跟着换。英文标题用和中文一样的墨色、稍小的字号。

## 检查

自动检查 136/136、启动流程 6/6、联机 12/12。1080p 帧率：湖畔 21 机位平均 100.2 FPS，其他世界 160–276 FPS（这一版只动界面，卷轴只写一种语言后每幅少一半文字行）。

- 新增 `_test_play_modes`：v0.5 旧档按有无任务分进两个槽；剧情开局（任务开）、存到另一天；再开休闲（没有任务、写休闲槽），两个存档都在、日子各是各的；休闲模式下图腾只闲聊、小屋门推开就进、新星座都在天上、终章不会来；读回剧情槽，模式和日子都对；正在玩剧情时“创建房间”先存剧情、转去建休闲世界，不会用剧情世界开房间。测试把存档文件夹改到 `user://test_play_modes`，不碰真的存档。

- `_test_game_rules`、`_test_new_game_menu` 按新规则改：任务跟着游戏模式走；设定页不列游戏模式和任务开关，开始后是休闲模式、写休闲槽。
