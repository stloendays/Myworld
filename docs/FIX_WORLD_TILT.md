# 修复：进入世界后立牌飘在天上、独木舟看不见、桥一直闪（2026-10-24）

## 原因

桌面入口直接运行 `D:\个人世界\DuskLake` 里的工程源文件。那里的 `scenes/main/Main.tscn` 在今天 11:44 被 Godot 编辑器重新保存过（v0.4.0 的 exe 在 11:34 已导出，所以 exe 不受影响）。保存时根节点 `Main` 带上了一个绕 X 轴约 37.6° 的旋转，`Cabin`、`PoolHouse`、`Player` 也被写进了位移或旋转：

```
[node name="Main" type="Node3D" unique_id=549960001]
transform = Transform3D(1, 0, 0, 0, 0.792315, -0.61011225, 0, 0.61011225, 0.792315, 0, 0, 0)
```

多半是在编辑器视口里误拖了根节点后保存了。整个世界因此倾斜：

- 地形、湖、桥、溪水这些按 `Main` 的局部坐标生成的东西都跟着斜了；
- 立牌、独木舟是按世界坐标（`global_position`）摆放的，没有跟着斜。

于是立牌悬在半空，独木舟埋到斜下去的地形里，桥和溪水、地面交错在一起闪烁。

## 修复

| 改动 | 作用 |
|---|---|
| 把 `D:\个人世界\DuskLake\scenes\main\Main.tscn` 恢复成 git 里的版本 | 本机立刻恢复正常。被改坏的那份备份在 `D:\个人世界\_backup\Main.tscn.editor-saved-20261024-1144` |
| `Main.anchor_to_origin()`：`Main._enter_tree()` 在子节点摆放之前把 `Main` 和它下面所有 3D 节点放回原点，并在日志里报出被放回的节点 | 以后场景文件再被误存，运行时也不会倾斜（世界二 `World02` 同样处理）。木屋、泳池馆、玩家仍按布局和出生点摆放，不受影响 |
| `Main.tscn` 的根节点 `Main` 和地形 `World` 加 `metadata/_edit_lock_ = true` | 在编辑器视口里点不中、拖不动，不会再误拖 |
| 自动检查“世界根节点在原点” | 检查三件事：`Main.tscn` 里任何节点都不写 transform、position、rotation；根节点和地形已锁定；倾斜的场景树会被放回原点 |

## 验证

- 把那份被改坏的 `Main.tscn` 原样放进修复分支运行：启动日志提示已把 Main、Cabin、PoolHouse、Player 放回原点；
- `devtools/GlitchProbe.tscn`（新增，无窗口）逐块检查：10 块室外立牌都贴着地面（射线测得的地面与地形高度相差不超过 0.01 m），独木舟在码头南侧水面上，模型已加载。
- 截图 `screenshots/fix_01`–`fix_04`（同样用改坏的场景跑）：
  - 步道立牌站在地上；
  - 独木舟停在码头边；
  - 溪上木板桥、裂谷原木桥都架在原位。
- 闪动探针（`devtools/FlickerProbe.tscn`，新增两座桥的机位 `fb1`、`fb2`）：
  - 裂谷原木桥 0 个像素闪动；
  - 溪桥机位 0.24% 的像素闪动，都在流动的溪水泡沫上（热力图确认），桥本身不闪。
  - 关掉防护再跑改坏的场景：这个机位的相机直接埋在倾斜的地下，桥板悬在半空、和树林交错。
