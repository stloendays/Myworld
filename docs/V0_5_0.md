## 启动保护：别的电脑打不开的修复

朋友的电脑上打不开。原因有两类，exe 本身是单文件、不需要装 Godot 或任何插件：

1. **显卡驱动**。游戏默认用 Forward+（Vulkan）。引擎在 Vulkan 起不来时会自己依次换 D3D12、OpenGL（`fallback_to_d3d12`、`fallback_to_opengl3` 默认开），但驱动能起来、加载到一半崩掉时引擎不会换。
2. **Windows 拦截没有签名的 exe**（SmartScreen“Windows 已保护你的电脑”，或杀毒软件隔离），看起来像“打不开”。

改动：

| 改动 | 做法 |
|---|---|
| `StartupGuard`（第一个 Autoload） | 每次启动在 `user://startup_guard.json` 记 `starting`，世界画出来后（BootLoader 预热完）记 `ok`，正常退出记 `exited`。下次启动看到 `starting` = 上次加载途中崩了，自动降一级：标准 → 兼容（OpenGL）→ 兼容 ANGLE（OpenGL 走 Direct3D 11），写进设置，并带 `--rendering-method gl_compatibility --rendering-driver …` 重新启动自己。只在导出的游戏里起作用；命令行自己指定了渲染方式时不动 |
| 设置 → 画面 → 渲染方式 | 自动（推荐）/ 兼容（旧显卡、打不开时）/ 兼容 ANGLE，旁边显示现在实际用的渲染方式和驱动，改了出现“重启生效” |
| 兼容渲染下关掉 Forward+ 才有的效果 | 屏幕空间反射、TAA、FSR 只在 Forward+ 下开（`PerformanceDirector.forward_plus()`），兼容渲染改用普通缩放 |
| 诊断记录 | `startup_guard.json` 记版本、系统版本、渲染方式、驱动、显卡名；日志开头也打印同一行 |
| 窗口图标 | `installer/icon.ico` 以前没打进包，启动时报 “Cannot open file with icon”；现在打进包 |
| `DUSK_PARK_WINDOW=1` | 导出的 exe 冒烟测试时窗口停在屏幕外（和开发工具一样） |

### 实测（本机导出的 v0.5.0 exe，全新的用户目录）

| 场景 | 结果 |
|---|---|
| 全新用户目录直接启动 | 20–31 s 走到游戏画面（第一次要编译着色器），`vulkan / forward_plus`，状态 `ok` |
| 伪造“上次加载途中崩了”再启动 | 第一个进程自动退出，带参数重新启动；新进程用 `opengl3 / gl_compatibility` 走到游戏画面，设置里渲染方式记成 `compatibility` |
| OpenGL 兼容渲染截图（湖畔、卷轴、亚特兰蒂斯） | 画面正常，只少了反射、TAA |

### 朋友还是打不开时

1. 出现“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。杀毒软件拦了就把 `DuskLake.exe` 加进信任。
2. 下载完整：文件约 162 MB，可以用 `Get-FileHash DuskLake.exe` 对照发布页的 `DuskLake.exe.sha256`。
3. 系统要 64 位 Windows 10 / 11。
4. 打开过但闪退：再双击一次（第二次会自动换兼容渲染）。还不行就把 `%APPDATA%\DuskLake\startup_guard.json` 和 `%APPDATA%\DuskLake\logs\godot.log` 发过来。
