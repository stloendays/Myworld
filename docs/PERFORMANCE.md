# 性能优化记录（2026-10-21）

目标：笔记本（RTX 5060 Laptop，165 Hz 屏）上稳定流畅，不满负荷发热。做法参考主机 / PC 大作的常规流程：先剖析找瓶颈，再针对性优化，最后用帧率上限和动态分辨率兜底。

## 1. 剖析：钱花在哪里

新增 `devtools/Profile.tscn`：在最慢的三个机位逐项关掉一个特性，比较帧时、CPU / GPU 时间、绘制调用和三角形数。

| 发现 | 数据（优化前） |
|---|---|
| 每帧三角形数过多 | 每帧约 **630 万**，其中约 420 万来自树木投影，约 330 万来自炉火灯（唯一开阴影的点光源）的立方体阴影 |
| 原因 | 全图约 2400 棵树按模型合成十几个巨大的 MultiMesh，包围盒覆盖整张图，所以视锥剔除、阴影级联剔除和点光源阴影剔除全部失效。炉火灯阴影范围只有 6.5 m，却每帧把全图的树画 6 遍 |
| 地下水族馆照样画整片树林 | 在地下看不见树，但树林和太阳阴影照算 |
| 默认不限帧率 | 跟着 165 Hz 屏幕满负荷跑，GPU 长时间接近 100% |
| 屏幕空间效果 | SSR、SSAO、4 级太阳阴影各约 1–3 ms |

## 2. 优化

| 做法 | 实现 | 效果 |
|---|---|---|
| 空间分块（cell 分区） | `ForestBuilder` 把树和岩石按 64 m 方格分块，每块一个 MultiMesh（共 328 块、16 个方格） | 视锥剔除、阴影级联剔除、点光源阴影剔除和网格自动 LOD 生效。开阔机位每帧三角形从约 630 万降到约 170–190 万 |
| 遮挡剔除 | 开启 Godot 遮挡剔除；`TerrainBuilder` 生成 4 m 间距的粗地形遮挡体，每点取周围最低高度再压低 0.5 m，永远在地面以下，不会误剔地面上的草和石头 | 山包后面、地下水族馆四周的东西被挡住就不画 |
| 地下关太阳阴影 | 玩家在地下水族馆时，`PerformanceDirector` 让 `EnvironmentDirector` 不算太阳阴影 | 地下水族馆每帧三角形从约 630 万降到约 **37 万**，绘制调用从约 3500 降到约 590 |
| 局部灯距离淡出 | 所有点光源 40 m 外淡出，阴影 18 m 外淡出 | 远处的灯和阴影不再计算 |
| 画质分级 | 设置 → 画面 → 画质：低（轻薄本）/ 中 / 高（推荐，默认）/ 极高。档位控制 SSR 步数、SSAO（半分辨率）、太阳阴影级数与距离、阴影贴图大小、MSAA、网格 LOD 阈值、灌木等地被是否投影 | 低档关 SSR、SSAO、MSAA，太阳阴影 2 级 60 m |
| 帧率上限 | 默认 **60 FPS**，可选 30 / 60 / 120 / 144 / 165 / 240 / 不限 | 不再跟着 165 Hz 满负荷跑；按下表的 GPU 时间，60 FPS 时 GPU 只忙约 25–35% |
| 动态分辨率 | 默认开。每 0.5 s 取 GPU 帧时的 75 分位：超过预算的 90% 渲染比例降 5%（最低 60%），低于 60% 升回去；低于 100% 时用 FSR 1.0 放大 | 场景突然变重时帧率稳住，画面略软但不卡 |
| AI 降频 | 动物离相机 70 m 外每 4 帧更新一次，150 m 外每 12 帧一次（跳过的时间累计，速度不变）；鱼群在相机离鱼缸 45 m 外不更新 | 省 CPU |
| 小型粒子用 CPU | 烟囱炊烟只有 40 个粒子，用 CPUParticles3D | — |

自动检查（无窗口）不受帧率上限影响，`--fixed-fps 60` 照样全速模拟。`Benchmark` 和 `Profile` 启动时自动关掉帧率上限、动态分辨率和垂直同步，测的是渲染能力本身。

## 3. 优化后的数据

`devtools/Benchmark.tscn`，1920×1080，高画质，不限帧率，关闭垂直同步：

| 机位 | 帧率 | GPU | CPU 渲染 | 绘制调用 | 三角形 |
|---|---|---|---|---|---|
| 湖岸出生点 | 127 FPS | 3.9 ms | 4.7 ms | 2072 | 165 万 |
| 码头望木屋 | 95 FPS | 4.4 ms | 4.9 ms | 3578 | 188 万 |
| 木屋室内 | 91 FPS | 5.7 ms | 5.5 ms | 3513 | 279 万 |
| 北部林道 | 116 FPS | 4.7 ms | 6.1 ms | 2612 | 186 万 |
| 秋夜大雨·木屋外 | 140 FPS | 4.4 ms | 3.4 ms | 1484 | 238 万 |
| 冬日下雪·湖岸 | 119 FPS | 4.0 ms | 4.7 ms | 2744 | 179 万 |
| 泳池馆大厅 | 127 FPS | 6.0 ms | 4.0 ms | 1699 | 122 万 |
| 地下水族馆 | 150 FPS | 5.7 ms | 2.6 ms | 591 | 38 万 |
| 夏夜雷雨·湖岸 | 136 FPS | 4.4 ms | 4.4 ms | 2335 | 175 万 |

- 不限帧率时的数字在连续测试中波动约 ±20%，笔记本温度变化的影响比单项优化的差别还大。所以上面三角形数和绘制调用是确定的，帧率只看量级。
- 真正决定“电脑能不能正常运行”的是：默认 60 FPS 上限下 GPU 只用到约三成，外加动态分辨率兜底。
- 分块后，开阔视野下的绘制调用比优化前多（约 800–2700 → 1500–3600）。这是空间分块的正常代价，CPU 渲染时间仍在 2.6–6 ms，远低于 60 FPS 的 16.7 ms 预算。

## 4. 自动检查

`性能` 一项检查：
- 树林已分块（每块有方格坐标，分块规则正确）；
- 遮挡剔除开启且有地形遮挡体；
- 低 / 高画质参数正确；
- 动态分辨率能降到 60%（启用 FSR），也能升回 100%；
- 默认帧率上限 60，无窗口时不限；
- 所有局部灯都开了距离淡出；
- 进入地下水族馆关太阳阴影，出来恢复；
- 远处动物降频。
