# 启动画面、加载界面、开场过场、转场黑幕，第一人称双手缩小与右键（2026-10-24）

## 启动流程

| 阶段 | 画面 | 实现 |
|---|---|---|
| 引擎启动 | 暮色底色上的湖畔图标（`boot_splash.png`，由 `devtools/make_icon.gd` 和图标一起生成），底色与加载界面顶部同色，接得上 | `project.godot → application/boot_splash/*` |
| 加载 | 暮色渐变背景、慢慢飘的萤火虫、图标与标题、进度条、阶段文字（正在加载湖畔… → 正在搭建世界… → 正在点亮暮色… → 准备好了）、每 4.5 秒换一条小提示（11 条，中英都有）、右下角版本号 | 主场景改为 `scenes/boot/Boot.tscn`（`BootLoader`），画面是 `LoadingScreen` |
| 开场过场 | 上下电影黑边，三段镜头：高处越过湖面看落日并出现标题 → 贴着水面沿码头滑向木屋 → 从木屋东侧步道上方落到玩家眼睛的位置；段与段之间短暂黑场；右下角“按任意键跳过” | `IntroCutscene`，镜头写在 `world_layout.json → intro` |
| 主菜单 | 过场结束交还玩家相机，从黑幕里亮起，弹出原来的大厅菜单（单人 / 建房 / 加入） | `LobbyMenu` |

- 加载按 `worlds.json → current` 读当前世界的场景（一般是暮色湖畔 `Main.tscn`），后台线程读取，读完实例化、加到根节点下并设为 `current_scene`。之后 `WorldTravel` 换世界时照样按 `current_scene` 接着换。全程不切换场景。
- 世界加进来以后，在加载画面后面先渲染 40 帧，把着色器编译完，进游戏时不卡。
- 每一步都写日志（带毫秒）。后台读取 20 秒没有进展会报错，方便查“卡在加载”。
- 过场只在暮色湖畔播放。设置 → 视角 → “启动时播放开场动画”可以关掉；命令行 `-- --skip-intro` 跳过；`-- --host`、`-- --join` 直接建房或加入时也不播。过场期间其他界面隐藏、人物站定、鼠标环视锁住，结束后全部恢复。
- 跨世界旅行（图腾山洞的光门）改用同一套加载画面：标题下写“正在前往「…」……”，阶段为正在收拾行囊… → 正在读取新世界… → 正在搭建世界…。

## 转场黑幕

`Fade`（Autoload）是盖在所有界面之上的一块黑幕，可以带一行文字：

- 启动：加载画面淡出 → 黑幕 → 过场或主菜单从黑幕里亮起；
- 加入朋友的房间：一下子黑掉，写“来到 某某 的湖畔”，再慢慢亮起，盖住时间、天气、门一下子同步过来的跳变；
- 房主关房、回到自己的湖畔：同样一黑一亮，写“回到你自己的湖畔”；
- `/tp` 传送、开发者面板传送：黑一下再亮起（开发者传送时写地点名）。

## 第一人称双手

| 改动 | 说明 |
|---|---|
| 变小 | 默认大小 0.5（设置 → 视角 → “手的大小”，40%–100%）。每只手以手尖为中心整体缩小：手在画面上的落点不变，手臂和拳头变短变细；手尖离相机约 0.25 m，仍在碰撞体以内，贴墙不会插进墙里 |
| 位置 | 两只手分在画面左右下角（右拳约在横向 78%、竖向 77%），画面中间一条不挡。肩位和角度由目标落点反推（`FirstPersonArms.SHOULDER / POSE`） |
| 看得出是手 | 外套、卫衣的袖子一直盖到手腕，以前第一人称只看得到袖子。现在两只手末端各有一个皮肤色的方块拳头（只在第一人称手上，第三人称方块人不变），肤色随外观变化 |

## 右键

右键是“用手”：

- 准星对着能用的东西（门、灯、炉子、座位、床、独木舟、棋盘……）就和按 E 一样去用，手往前一伸；
- 什么都没对着就挥挥右手：第一人称看到右手举到画面右侧偏上、左右摆三下，联机时别人看到你的方块人在挥手；不会切到第三人称，约 2.6 秒后自己停，走动也会停。

暂停菜单的按键说明改为“E 或右键 交互”，加载提示里也有一条。
