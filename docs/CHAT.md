# M2 扩展：聊天框 验收记录（2026-10-21）

左下角的聊天框：可以随手写几句话，用 `/` 命令改时间、天气、季节、传送，天气和季节变化会作为系统消息出现。界面和输入在 `scripts/ui/ChatBox.gd`，命令在 `scripts/ui/ChatCommands.gd`，由 `Main` 启动时创建。

## 操作

| 操作 | 按键 |
|---|---|
| 打开聊天 | T 或 Enter |
| 直接输入命令 | /（输入行预填 `/`） |
| 发送 | Enter（发送后自动关闭） |
| 取消 | Esc，或点输入框以外的地方（Esc 只关聊天，不打开暂停菜单） |
| 翻输入历史 | ↑ / ↓ |
| 翻看记录 | 打开时用鼠标滚轮 |

- 打开时释放鼠标，人物原地站定（按 W 不走），关闭后恢复。暂停菜单打开时不能打开聊天。
- 关闭时左下角只浮现最近 8 条、10 秒内的消息，最后 1.5 秒渐隐；打开时显示全部记录（最多 200 条）和半透明底板。
- 每条消息最长 200 字。方括号原样显示，不会被当作富文本标记。
- 聊天名字默认“旅人”，用 `/name` 修改后存到 `user://chat.json`。

## 命令

| 命令 | 作用 |
|---|---|
| `/help` | 列出命令 |
| `/time [时:分]` | 查看或设置时刻，例如 `/time 18:30` |
| `/weather [天气]` | 查看或切换天气（晴 阴 小雨 大雨 雷雨 雾 下雪，或 `CLEAR` 等 id），8 秒过渡；本季不会出现的天气会被拒绝 |
| `/season [季节]` | 查看或跳到某季第一天（春 夏 秋 冬，也可写“春季”“春天”或 id） |
| `/preset [名称]` | 应用 `weather.json` 里的预设；不带名称列出全部 |
| `/pos` | 当前坐标与所在区域 |
| `/tp <x> <z>`、`/tp 出生点` | 传送到室外地面。超出 ±105 m、落在湖面或建筑占地（`keepouts`）内会被拒绝——进屋必须走门 |
| `/name <名字>` | 修改聊天名字（1–16 字） |
| `/me <动作>` | 以第三人称描述动作，例如“* 旅人 坐在湖边看日落” |
| `/clear` | 清空记录 |

中文别名：`/帮助` `/时间` `/天气` `/季节` `/预设` `/坐标` `/传送` `/名字` `/清屏`。

## 系统消息

- 启动时的欢迎提示。
- `EventBus.weather_changed`：天气过渡完成时“天气转为小雨。”
- `EventBus.season_changed`：“进入冬季。”

聊天框只订阅事件、调用 `ClimateSystem` 等已有入口，不保存世界状态。
