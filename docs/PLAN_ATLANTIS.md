# 计划：亚特兰蒂斯（世界四）+ 更多玩法（2026-10-26）

分支 `feature/atlantis-more-play`，从 v0.5（PR #25，`feature/v0.5-worlds-scrolls-newgame`，2149daa）分出，worktree `D:\个人世界\DuskLake-atlantis`。PR 的 base 是 v0.5 分支（叠加 PR）。

调研结论（只读）：

- 新世界走 v0.5 的 `MiniWorld` 底座：子类实现 `height_at` / `build_world` / `map_color` / `draw_map`，位置写进世界数据 JSON；`WorldTravel` 负责卸载、清缓存、后台加载。
- 水体只有盒子和圆柱两种（`WaterVolume.contains`），水里没有重力；`open_top = false` 的水体没有浮力（大缸就是这样）。
- 收集品只有一种外观；坐车 / 坐椅子走 `is_riding()`，没有“被水流带着走”的骑乘方式。
- 截图里沙丘、浮岛左下角写“欢迎来到暮色湖畔”：截图工具直接实例化世界场景，`WorldTravel.current_world` 还是湖畔，聊天框按它取名字。游戏里只要不是经 `WorldTravel` 加载的世界都会这样（根因：“当前世界”不是由世界根节点自己声明的）。

## 二、更多玩法（6 个，都有 `GameRules` 开关，联机做客时禁用并提示，房主照常玩）

| 玩法 | 做法 | 验收：自动检查 | 截图 |
|---|---|---|---|
| 钓鱼 | R 甩竿 / 收竿；湖（码头和湖岸）、绿洲、浮岛池塘、亚特兰蒂斯水环；鱼漂下沉后 1.5 s 内按 R 才钓得到；每片水有自己的鱼（12 种），进图鉴“鱼”栏并记最大尺寸 | 码头上甩竿落在湖里、咬钩后收竿得到湖里的鱼；地上甩竿提示“这里没有水”；咬钩后不收鱼会跑 | `play_01_fishing` |
| 打水漂 | 湖边按 Q 扔石头（准星越平、跑起来扔弹得越多），石头真的在水面上一跳一跳；记最多弹几下 | 平着扔弹 ≥ 3 下、往下扔 0–1 下，纪录写进存档 | `play_02_skipping` |
| 寻宝 | 按世界种子在 4 个世界各埋一只宝箱（候选点来自数据），旅行日志“寻宝”页给出线索；B 挖，离得远提示冷 / 热；挖到宝箱出现并记录 | 同一种子线索一样、不同种子不同；在宝箱处挖出宝箱，远处挖提示距离 | `play_03_treasure` |
| 成就 + 收藏柜 | 20 个成就（数据驱动），J → 成就页；木屋北墙一只收藏柜，摆出收集到的东西（云珠、碎片、珍珠、石板、宝箱、鱼标本、山铜） | 条件满足时解锁并提示；收藏柜按存档显示物件 | `play_04_cabinet`、`play_05_achievements` |
| 计时挑战 | 湖畔环湖跑、雪山登顶、沙丘冲刺、亚特兰蒂斯潜水环：走进起点金环开始计时，按顺序过检查点，到终点停表，记最好成绩和奖牌 | 自动驾驶跑完一条，成绩、奖牌写进存档；走错顺序不算 | `play_06_challenge` |
| 炉火烹饪 | 木屋铸铁炉旁的铁锅、沙丘营地篝火：用钓到的鱼做烤鱼 / 鱼汤 / 海鲜拼盘，吃了有效果（体力回复快、氧气更耐用、游得更快） | 鱼不够做不了；做好后扣鱼、效果生效且有时限 | `play_07_cooking` |

## 三、存档与联机

- 存档 v4 → **v5**：`achievements`、`records`（打水漂、挑战成绩）、`catches`（鱼的图鉴与最大尺寸）、`pantry`（鱼和菜）、`treasures`。v1–v4 都能迁移读入（自动检查读一份 v4 档）。
- 新规则：`fishing`、`skipping`、`treasure`、`achievements`、`challenges`、`cooking`、`oxygen`，新分组“玩法活动”；悠闲模式关挑战和氧气，摄影模式关挑战和氧气，挑战模式全开。
- 联机：这些玩法都只改本机玩家自己的记录，不改共享世界；访客按键时提示“联机做客时不能……”，房主照常玩并存档。协议不变（亚特兰蒂斯和其他世界一样联机时不能去）。

## 四、顺手修

- “欢迎来到暮色湖畔”：世界根节点（`Main`、`MiniWorld`）进树时自己声明当前世界，聊天框、罗盘等都按它；截图工具的聊天机位按当前世界写。回归检查：直接实例化沙丘场景时欢迎语是“琥珀沙丘”。
