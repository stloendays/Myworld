# 第一章收尾：新星座、暮烬之夜、终章与剧情过场（世界观落地②，2026-10-26）

分支 `feature/story-embers`，基于 v0.5.1 的 main（4438f61），worktree `D:\个人世界\DuskLake-story`。

主线按定稿的世界观走：暮色湖畔是停在黄昏里的渡口，门后的世界各有一盏熄了很久的灯，旅人替走不开的老图腾把光送回去。
这一版把 `worldview.md` 里待落地的②（点亮世界后夜空多一个星座）、③（暮烬之夜，用原版红点）、⑤（图腾的收尾台词）做进游戏，
并给剧情的关键处配上过场动画：开场多了两行序幕，三个世界点亮的那一刻、湖畔新星座出现、暮烬第一次飘起、图腾讲完最后一个故事，各有一段。

## 玩家会经历的剧情

1. **开场**：原来的三段镜头后两段加上序幕字幕——“湖边有几道很老的门，门后面的世界，都停在黄昏里”“北边的山洞里，守火的老图腾在等一个旅人”。
2. **图腾的新任务**：「云上的风灯」（第四个，排在划船人的信之后，去洞尽头的光门点亮四座风灯）、「沙里的碎片」（第七个，沙之门后把六块碎片嵌回祭坛）。原来亚特兰蒂斯的两个任务不变。
3. **把光送回去的那一刻**：每个世界完成主线谜题时放一段过场——
   - 云海浮岛：风灯特写 → 天鲸从云海深处游过来 → 镜头转向云海的落日：“远远的湖畔，夜空里多了一颗星”；
   - 琥珀沙丘：祭坛上的六块碎片 → 神殿光柱升上天 → 石像头望着的落日：“石像头一直望着的落日那边，就是湖畔”；
   - 亚特兰蒂斯：山铜尖塔亮起 → 神殿大门打开 → 城外的老鲸鱼第一次游到穹顶边上（鲸鱼从 96 m 外游近到 72 m，以后一直在近处）。
4. **湖畔的新星座**：回到湖畔，第一个晴朗的夜里、人在室外时自动放一段过场：镜头站到湖上、隔着湖望向那片天，星一颗一颗亮起来（亮的一下大一圈），再一笔一笔连上线，字幕说出它的名字（天鲸座 / 石拱座 / 蝠鲼座）。之后每晚都在，记进图鉴。
5. **补全星图**：石头小屋桌上那张没画完的星图，三个空位随新星座出现用金色新墨补上；三个都补上后说明换成「补完的星图」，“还差三个”那行被划掉。图腾任务「补全星图」、成就「补全星图」。
6. **暮烬之夜**：三盏灯都亮以后的傍晚（日落前 30 分钟到凌晨 4:30），湖面升起一层发光的暮烬，镜头周围飘起原版红点；第一次时天会放晴，并放一段过场（湖面的红光 → 升上天的火星 → 山洞口：“山洞里的火，好像在叫你回去”）。图腾任务「暮烬之夜」。
7. **图腾最后的故事**：暮烬飘着的夜里回山洞，图腾头上有金色标记；它讲六页：暮烬是什么、从前每个世界都有守火人、他们走远后世界停在黄昏里、划船的人临走说过“等三盏灯都亮了，暮烬就会回到湖上”、谢谢你、去石头小屋看看。
8. **终章过场**：篝火 → 暮烬从湖面升到天上 → 满天的星座连线一起亮 → 石头小屋的台灯不知什么时候亮了 → 标题「暮色湖畔 · 第一章 · 把光送回去 · 完」。
9. **第四封信**：石头小屋书桌上多了一封压着红火漆的信（划船的人回来过一趟，点了台灯，没敢等你；要去月光石门后面捡掉了一地的星星，挂回天上）。读完任务完成，成就「暮烬之夜」；图腾的收尾台词换成“往后每个晴朗的秋夜，暮烬都会回来……月光石门那边好像有人在敲”，留给第五个世界。
10. **以后**：讲完故事以后，暮烬只在晴朗的秋夜回来，并提示“湖上飘起了暮烬”。

所有过场按任意键跳过（跳过也不会漏掉结果：星座照样放出来、台灯照样亮）；设置 → 视角 →「剧情过场动画」可以关掉，关掉后只弹提示、结果直接放进世界。字幕中英两份、不加句号。

## 实现

| 模块 | 说明 |
|---|---|
| `Cutscene`（`scripts/story/Cutscene.gd`） | 通用过场播放器：电影黑边、镜头分段移动、每段一两行字幕或居中大标题、段间黑场、任意键跳过、藏界面锁人物、结束全部恢复。镜头点可以是锚点偏移（锚点带朝向时按它转）或另一个会动的锚点（每帧重取，跟得住天鲸、鲸鱼）。`cue` 信号让播放方在某段开头做事（星座亮起、暮烬飘满、所有连线亮、台灯亮） |
| `IntroCutscene` | 改成 `Cutscene` 的子类，只负责把标题放进第一段；镜头和序幕字幕仍在 `world_layout.json → intro` |
| `data/story/cutscenes.json` | 六段剧情过场：`cloudsea_light`、`dunes_light`、`atlantis_light`、`new_star`、`ember_night`、`finale`（镜头、字幕、标题、cue） |
| `StoryDirector`（湖畔，挂在 Main 下） | 每半秒看世界状态：放新星座、开关暮烬（含第一次放晴）、第一次暮烬过场、终章、小屋台灯与书桌上的信；给湖畔过场提供锚点（湖心、洞口、图腾、小屋、看星星的位置）。联机访客不放 |
| `EmberField` | 暮烬：贴着湖面冒出的 1800 个发光小方块，慢慢往上飘、随风斜、越飘越暗；不受光照、叠加混合。和它一起出现的镜头周围那层是原版红点 `legacy_red_motes`（`Precipitation.story_profile`，**参数原样**：700 个、静风 35 %） |
| `StarField` | 带 `requires` 的新星座在世界点亮前不在天上，盯着看也认不出；`reveal()` 让星一颗颗亮、线一笔笔连，放过的记 `flags.star_<id>`；`highlight_all` 让终章里所有连线一起亮（只是画面） |
| 各世界 | `MiniWorld.story_anchor()` / `play_story()`：spawn、sunset（所有世界朝着同一轮落日）；云海加 beacon、whale，沙丘加 altar、head、sunset，亚特兰蒂斯加 spire、temple_door、whale。世界点亮的那一刻（标记第一次写下时）放过场 |
| 任务与对话 | `quests.json` 新增 4 个任务（共 16 个），`requires`（前提标记，未满足时图腾说 `wait` 那句）、`finale`（最后的故事 6 页）、新的 `all_done`；目标 `constellations` 支持 `ids`。`DialoguePanel` 在暮烬之夜讲最后的故事，最后一页合上时交给 `StoryDirector` 放终章 |
| 信与星图 | `letters.json` 新增 `farewell`（第四封信，不算进三封信，读过记 `flags.farewell_read`）和 `chart_done`；`LetterSpot` 新增 `envelope`（压着红火漆的信纸和一颗白石子）；`ChartView` 把新星座画进空位；`StoneCottage.place_farewell()`、`refresh_chart()` |
| 设置、成就、翻译 | `GameSettings.story_cutscenes`（默认开）+ 设置页开关；成就新增「补全星图」「暮烬之夜」（共 27 个）；`en.tsv` 补 6 行 |

存档：全部是 `WorldState.flags` 里的新键（`star_sky_whale` / `star_stone_arch` / `star_manta`、`ember_night_seen`、`ember_night_heard`、`farewell_read`、`star_chart_done`），存档版本不变（v5）。旧存档里已经点亮的世界，回湖畔后第一个晴夜会补放新星座。
