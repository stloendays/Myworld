# M2 扩展：画面闪动优化 + 自然景观（小溪、瀑布、裂谷、两座桥）（2026-10-24）

分支 `feature/nature-streams`，叠在 #20（图腾山洞）上。

## 一、画面闪动

### 怎么查的

新工具 `devtools/FlickerProbe.tscn` + `devtools/flicker_report.py`：8 个机位（湖岸、码头望木屋、木屋室内、林道、远岸、洞口、南部草甸、泳池馆），
按固定 30 fps 连续渲染 60 帧存 PNG，逐像素统计。

- **相机不动、时间照常走**：“突然变一下又变回去”的像素只有 0.006–0.14 %，而且都是飞过的鸟、蝴蝶、落叶——没有 Z 冲突、没有静止时自己闪的物体。
- **走动时**：闪的是细东西和边缘——花草、栏杆、木板缝、立牌上的字、阴影边，属于锯齿在像素间跳（原来高画质只有单帧 SMAA）；
  另外草和花按 40 m 一整块抖动淡入淡出，走动时一整块草地同时冒出来或消失。
- 衡量锯齿闪烁用“相机左右来回转 1/3 像素”（画面内容不变，帧与帧差得越多越闪）：

| 机位 | SMAA（原来） | FSR2 | **TAA（现在）** |
|---|---|---|---|
| 湖岸 | 0.44 % | 0.54 % | **0.18 %** |
| 码头望木屋 | 1.05 % | 0.93 % | **0.32 %** |
| 木屋室内 | 1.24 % | 1.17 % | **0.68 %** |
| 林道 | 1.62 % | 2.32 % | **0.69 %** |
| 远岸 | 1.01 % | 1.27 % | **0.42 %** |
| 洞口 | 1.26 % | 1.42 % | **0.62 %** |
| 南部草甸 | 3.62 % | 3.91 % | **2.45 %** |
| 泳池馆 | 1.65 % | 1.75 % | **0.91 %** |

（帧间变化超过 5 % 的像素占比，越小越稳。）

### 改了什么

- **高 / 极高画质改用 TAA**（时间抗锯齿）：上表里闪烁像素大多降到一半以下。FSR2 也试了，没有更稳，没用。低 / 中画质仍是 FXAA / SMAA（省性能）。
  代价：每帧 GPU 多约 0.3–0.5 ms，显存多约 20 MB。
- **草、花、蘑菇远处逐株缩小消失**：植被着色器和新的 `cover_flat.gdshader` 按每一株离相机的距离（草和花 52 → 68 m，林下 45 → 60 m，蘑菇 30 → 40 m）
  慢慢缩小到 0；整块地被只在最远一株也缩没之后才剔除，不再整块抖动淡入淡出。小石头的可见距离 90 → 130 m。
- **动态分辨率防抖**：连续 2 次（1 s）超预算才降一档、连续 4 次（2 s）富余才升一档；开着动态分辨率时一直用 FSR，
  比例在 100 % 上下变动时不再在 FSR 和普通缩放之间来回切（以前每次跨过 100 % 画面锐度会跳一下）。
- 顺手修了一个白顶石头：单独摆放的 Kenney 石头（山洞外、溪边）顶上的苔藓没有 MultiMesh 实例颜色，显示成白色像积雪；现在给单独摆放的植被材质一个固定的苔绿色。

## 二、自然景观

### 西岭小溪与小瀑布

- 地形里的沟槽（`world_layout.json → terrain.channels → west_creek`）：从西边山坡（-114, -4）流到湖西岸（-33, 4），全长约 83 m。
  河床比原地面低 0.75 m、底宽约 2 m、两岸缓坡；沟底高度沿流向**只降不升**，离源头 17 m 处整体落下 1.8 m，形成一道**小瀑布**和下面的水潭。
- 水面（`Streams.gd` + `stream_water.gdshader`）：沿河床一条水带，每一处的宽度按两岸实际地面算到“刚好没过岸边”；
  两层程序噪声法线顺流滚动，瀑布和急流处泛白沫、流得更快，两岸边缘渐透明；流进湖里的地方结束。瀑布底下一团软边的水雾，跌水口两侧各夹一块大石头。
- 河床铺湖岸的砂石，溪边每隔几米一两块小石头，下游平缓处和入湖口长芦苇；河床和两岸 1.8 m 内不长树、不长草，小动物不进去。
- 水只有 30 cm 深，可以踩着走过去；北部林道过溪的地方有一座**木板桥**（微拱、两侧栏杆）。

### 北岭裂谷

- 西北观景小山被一道裂缝劈开（`north_gorge`）：全长约 47 m，最深 7.5 m，谷底宽 4 m、谷口约 8 m，两壁近乎垂直（地形自动铺岩石）。
- 两头 15 m 内渐渐变浅（最陡不到 40°），可以从东西两端走下谷底，再走出来。
- 北部林道跨过裂谷的地方架了一座**原木桥**（两根原木做梁、木板桥面、原木扶手），桥面和扶手都有碰撞，走在上面掉不下去。
- 两处都加了中英双语立牌和探索点（“西岭小瀑布”“北岭裂谷”，小地图问号 → 金色标记），开发者传送点同名。

### 实现

- `WorldTerrain` 新增沟槽：第一次调用时按原地形把沟底高度算好（1 m 一个点），`height_at` 只在沟槽包围盒里做一次最近点投影，
  碰撞、地形网格、树木、地被都用同一个高度函数，所以彼此一致。`channel_distance()` 给植被、地被、动物、地表材质避让。
- 桥面两端正好贴着地面，桥头再各接一段 1.5 m 的引坡斜到外面的实际地面（人物不会迈台阶，桥头不能有坎）。

## 自动检查（新增 3 项，共 88 项全部通过）

- 小溪：水面只降不升、有一道 1.8 m 的瀑布、流进湖里，河床比两岸低；裂谷最深 7.5 m、两头渐浅；河床谷底不长树
- 桥：走过木板桥过溪（桥面高于水面）、走过原木桥过裂谷（掉不下去，侧面有栏杆）；裂谷能从东头走到谷底再走出来
- 地被：草、花、蘑菇远处逐株缩小消失，整块只在全部缩没后才剔除（204 块）
- 原有检查的调整：高画质 = TAA、中画质 = SMAA；动态分辨率防抖；地形一致性检查跳过裂谷陡壁（1 m 网格的三角面插值在陡壁上本来就和解析高度不同）

## 性能（1920×1080，高画质 + TAA，关垂直同步）

| 机位 | FPS | GPU ms |
|---|---|---|
| 湖岸出生点（对照） | 100 | 3.9 |
| 西岭小瀑布 | 90 | 4.3 |
| 北岭裂谷 | 116 | 3.4 |

显存 668 → 687 MB（走完全部 17 个机位）。测量时完整自动检查在后台跑，FPS 受 CPU 占用影响，只适合和同一次的对照机位比较。
