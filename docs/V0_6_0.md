## 2D 地图重画

世界地图（Tab）、右上角小地图和三个别的世界的地图换成一张手绘风的地图。画法都在 `scripts/ui/MapArt.gd`。

| 部分 | 做法 |
|---|---|
| 湖畔底图 | 256 → 512 像素，分 16 条在线程池里并行烘焙（地形高度、植被密度的缓存先在主线程建好，线程里只读），烘一次缓存到 `user://`。按高度配色（湖边草地 → 草地 → 高地）、按坡度变岩石、雪线以上积雪 |
| 山体明暗 | 西北偏上来光，平地亮度不变，迎光坡亮、背光坡暗 |
| 等高线 | 每 2.5 m 一根细线，每 10 m 一根粗线（别的世界每 3 m） |
| 树冠 | 每 6 像素一格，按树密度随机放一棵圆形树冠，西北边亮、东南边暗；雪地和陡坡上不放 |
| 湖水 | 由浅到深的蓝，两道浅色等深线，岸边一道白线 |
| 纸面 | 每个像素一点细纹；可活动区以外的山坡压暗，像图纸的边 |
| 矢量层 | 描边的路；小溪画成蓝线（流进湖为止），裂谷画成深色岩带；木屋、泳池馆（里面一块蓝色泳池）、石头小屋画成带投影的图标；码头描边；探索点找到了是带星的金色图钉，没找到是问号；光门、沙之门是发光的紫色圆环；独木舟是红色小船 |
| 地图装饰 | 双线边框和四角菱形、八角指北针、黑白分段比例尺（0 / 25 / 50 m）、描边地名 |
| 玩家 | 箭头加投影、呼吸的光圈、18 m 的视野扇形 |
| 世界总览 | 每个世界一颗带光晕和高光的球，现在所在的那颗外面一圈呼吸的金环 |

地图、日志、暂停这些面板开着时，没在打字的聊天记录不再露在面板边上。

## 自动清理旧版本

朋友从网页下载新版时，浏览器常把新文件存成 `DuskLake (1).exe`，旧的那个一直留在下载文件夹里。现在新版本启动后会把电脑上认出来的旧版本移到回收站：

- **只认官方发布过的文件**：`data/releases.json` 里记着历次发布（v0.3.0 起）exe 的大小和 SHA-256。大小对上了才算哈希，哈希对上、而且版本比正在运行的旧，才算旧版本。同名但内容不同的、改过的、更新的版本，一概不碰。
- **去哪找**：正在运行的 exe 所在的文件夹、下载文件夹、桌面里名字以 DuskLake 开头的 .exe，加上以前运行过的位置（`user://installs.json`，从这一版起每次启动记一笔，下一版就能找到放在别处的这一版）。
- **怎么删**：后台线程里认，认完在主线程里移到回收站（不是直接删，想要还能还原），同目录的 `.sha256` 校验文件一起移走。大厅右下角的版本条上会写“已把旧版本 v0.5.1 移到回收站”。
- **可以关**：设置 → 关于 →“自动把电脑上的旧版本移到回收站”。
- 自动更新本来就是原地替换（旧 exe 先改名 `.old`、替换成功后删掉），不留旧文件。
- 测试参数：`-- --cleanup-dirs 目录1;目录2` 只查这几个目录、不读也不写运行记录；`-- --no-cleanup` 不清理。
- 以后发版前把上一个版本的大小和哈希加进 `data/releases.json`。
