# v0.4.0 发布（2026-10-24）

- 发布页：https://github.com/stloendays/Myworld/releases/tag/v0.4.0 ，附件 `DuskLake.exe` + `DuskLake.exe.sha256`。
- 内容：#17、#20、#21 合并后的 main。
  - 图腾山洞、9 个任务、旅行日志与图鉴、星座、石头小屋、跨世界旅行，见 [CAVE_QUESTS.md](CAVE_QUESTS.md)；
  - 画面闪动优化、西岭小溪与小瀑布、北岭裂谷与两座桥，见 [NATURE_FLICKER.md](NATURE_FLICKER.md)。
- 版本号：`project.godot` → `config/version = 0.4.0`，`export_presets.cfg` → 文件版本 / 产品版本 `0.4.0.0`。
- 联机：双方游戏版本需同为 0.4.0；联机协议仍是 2。
- 存档：任务与图鉴写在 `user://journal.json`（存档版本 3）；老版本没有这个文件，第一次打开就是空的。
- 老版本（v0.3.x）启动时查到 v0.4.0 会在大厅提示“发现新版本 v0.4.0 · 更新并重启”。
