# M2 扩展：图腾山洞、任务与图鉴、星座、石头小屋、跨世界旅行（2026-10-24）

分支 `feature/cave-quests`，叠在 #17（`devtools/offscreen-window`，开发工具窗口不打扰）上。

## 图腾山洞

- 位置：地图北缘的岩脊（`world_layout.json → cave`），洞口朝南，就在雪山步道边上（开发者传送点“山洞口”“图腾石厅”）。
- 洞道沿 `centerline` 弯曲，每个中线点的截面是一道拱（`profile`：半宽、拱高），中段放宽成石厅（约 13 m 宽、6 m 高）。
  内壁朝里、外壳朝外，外壳比内壁多出 4.6 m 宽、5.2 m 高并加噪声起伏，从外面看是一座岩丘；岩丘表面散着 Kenney 大石头。
  内外两层都是三角网碰撞（双面），洞外爬不进石头里，洞里撞墙不穿。洞底就是地形（`cave_pad` 压平到 2.2 m），上面铺一层碎石泥地。
- 洞里是室内区域（`zone_id = cave`，一个 ZoneArea 挂多个沿洞道旋转的盒子），雨雪落叶进不来。
- 石厅北墙下立着**老图腾**（`CaveTotem`）：三节方块雕刻（熊脸、红色鸟脸、展翅的雷鸟），眼睛是会发光的青色方块，说话时更亮；
  有新任务可接时头顶转着一颗金色菱形。
- 石厅中间一堆**篝火**：Kenney 石圈和木柴、火苗（GPU 粒子）、火星（CPU 粒子）、带阴影的摇曳火光；按 E 熄灭 / 点燃（`uid = cave_bonfire`）；
  三根原木围着火堆，可以坐。
- 洞道两侧几簇发光水晶照路；**尽头**一圈岩石围着一道光门（`FairyPortal`，`uid = cave_portal`），按 E 前往下一个世界。

## 任务（老图腾）

- 内容在 `data/quests/quests.json`（中英两份文字）。看着图腾按 E 打开对话框：第一次见面先打招呼 → 谢谢你完成的任务 → 给下一个任务（“好，我这就去 / 等会儿再说”）。
  对话框是屏幕下方一块面板，字一个一个打出来；E / 空格 / 回车继续，1–3 选选项，Esc 离开；打开时人物不能动。
- 九个任务，按顺序一个一个给，同时最多 3 个进行中，目标完成就自动记为完成并弹出提示：

| 任务 | 目标 |
|---|---|
| 篝火边的老朋友 | 坐到篝火旁的原木上 |
| 巡湖 | 找到湖心小岛、北岸芦苇湾、东岸睡莲湾 |
| 登高 | 登上雪山顶 |
| 林间的邻居 | 图鉴里记下 5 种动物 |
| 深潜 | 游进海洋大缸 |
| 码头上的舞 | 在码头尽头跳一支舞（G 动作轮盘） |
| 雨后 | 在室外看见一道彩虹 |
| 观星人 | 夜里找到 3 个星座 |
| 夜访仙境 | 在仙境出现时走进仙境林地 |

- 目标检查（`QuestLog`，每 0.4 秒）只读世界状态：发现过的地方、玩家所在区域与位置、彩虹强度、水体、动作、图鉴条数；座位“坐下”从
  `interactable_state_changed` 记下来。九个任务全部完成后，图腾说一段结束语（光门已经醒了，下一个世界还在长）。
- 左上角任务追踪：进行中的任务标题和当前进度（最多 3 条，没有任务时不显示）。

## 旅行日志与图鉴（J）

- J 打开 / 关闭（Esc 也能关）。「任务」页：进行中的任务和每个目标的进度、已完成的任务、还剩几个没接；
  「图鉴」页：动物（陆地动物走近 9 m、缸里的鱼游过身边 6 m 就记下，14 种）和星座（5 个），没见过的显示 ？？？。
- 新记一条会弹出“图鉴新增：兔子”之类的提示。

## 星座（观星）

- `data/sky/constellations.json`：原创的五个星座——独木舟座、狐狸座、灯塔座、松果座、图腾座，各在固定方位角 / 仰角。
- 星和连线是贴在以相机为中心、半径 600 m 球面上的小面片，跟着相机走；山和树照样挡得住。只在晴天的夜里出现（阴天、雨雪雾都看不见），白天淡出。
- 在室外盯着一个星座看（视线中心 10° 以内）1.5 秒，连线慢慢亮起来并记进图鉴；认出过的星座以后每晚都带连线。躺下（G → 休息两次）看天最方便。

## 石头小屋

- 南部草地（`world_layout.json → cottage`，传送点“石头小屋”），门朝西边的草地步道：毛石墙、石板坡屋顶、烟囱、三扇暗着的小窗、门前石阶、没点的挂灯，门口一块立牌。
- 门锁着（`LockedDoor`，`uid = cottage_door`）：准星对着提示“门锁着”，按 E 只弹一句话；整栋一个碰撞盒，进不去。以后做室内时把门换成 `InteractableDoor`。

## 跨世界旅行（不同时加载）

- `WorldTravel`（Autoload）：先渐黑 → **把当前世界整个卸掉**（世界根节点 `world_root` 组 queue_free，等它离开场景树）→ 清掉只有它用的材质、贴图、Kenney 模型缓存（`ArtMaterials.clear_cache()`）
  → 在后台线程读下一个世界的场景（加载画面显示进度）→ 实例化放回原来的父节点 → 渐亮。两个世界任何时候都不会同时在内存里。
- 不调用引擎的切场景函数：世界根节点在原父节点下被换掉，所以自动检查（世界挂在 TestRunner 下）和游戏里（世界是主场景）走同一条路；
  “室内外同一场景”的规则不变（进屋仍然只是走进一个区域）。
- `data/worlds/worlds.json`：世界二改为 `preview`（建设中但能进去），`scene` 指向占位场景；`arrivals` 写从某个世界过来时站的位置——回暮色湖畔时站在山洞光门前、面朝洞道，开始菜单不弹。
- 世界二（`scenes/worlds/World02.tscn`）现在只是雾海里的一座浮岛：一块“建设中”的立牌、一道回暮色湖畔的光门，自带玩家、HUD 和暂停菜单。
  仙境林地的月光石门也通往这里（以前只提示“还在建设中”）。
- 联机房间里不能离开（房间里的人都在同一个世界）；规划中的世界（世界三）仍然只提示“还在建设中”。

## 性能

`devtools/Benchmark.tscn`（1920×1080，高画质，关垂直同步）新增三个机位，和同一次测量里的老机位对比：

| 机位 | FPS | GPU ms | 每帧三角形 |
|---|---|---|---|
| 湖岸出生点（对照） | 92 | 3.6 | 134 万 |
| 山洞口 | 110 | 4.1 | 191 万 |
| 图腾石厅 | 142 | 4.5 | 189 万 |
| 石头小屋 | 90 | 3.3 | 140 万 |

显存 646 → 666 MB（走完全部机位）。测量时另有一个外部 Python 计算进程占着约 7 GB 显存，帧率比平时低、波动大，只适合和同一次的对照机位比较。
洞壁同时作为遮挡体（`OccluderInstance3D`）；石厅里每帧的三角形大多来自太阳阴影（阴影不受相机遮挡影响），帧率已经够用，没有为洞里关太阳阴影（关了阳光会直接照亮洞底）。

`devtools/MemProbe.tscn` 的路线加进了山洞（洞口 → 石厅 → 光门 → 出洞）：走完全图静态内存 266 → 272 MB，没有边走边涨；山洞这几段只有 1 帧超过 33 ms。
