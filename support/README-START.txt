DUSK LAKE v0.3.4-rc.1 - WINDOWS PORTABLE TEST BUILD
====================================================
QUICK START
  Double-click "Play-DuskLake.cmd" (recommended).
  The launcher tries the built-in Forward+ renderer first.
  If the EXE exits before the initial rendered scene is confirmed, it
  tries OpenGL Compatibility + low graphics settings automatically.

ALTERNATIVE
  Double-click DuskLake.exe to bypass the external recovery launcher.
  The game itself saves local startup diagnostics for troubleshooting.

DIAGNOSTICS
  Run "Run-Diagnostics.cmd" for manual tests or logs-only collection.
  A ZIP report is saved on the Desktop. Review it for private paths
  and usernames before sharing. Reports are never uploaded.

IMPORTANT
  Forward+ comes built into the Godot engine. It is not downloadable.
  Vulkan support is supplied by your graphics hardware and driver.
  Official Godot export templates are downloaded on the build machine,
  not on players' PCs. No GPU drivers are silently installed.

  Windows 10/11 64-bit. This is a prerelease to diagnose startup crashes.
  It has not been tested on the specific PC where the crash occurred.
